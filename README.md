# diskimg — комплекс программ для работы с образами дисков

Лабораторная работа: извлечение файлов из образа в локальный каталог, создание
нового образа, удаление файлов, добавление и замена файлов — для образов дискет,
CD/DVD и жёстких дисков (raw и VHD) с файловыми системами FAT и NTFS.

## Что поддерживается

| Формат | Чтение / извлечение | Создание | Добавление / замена | Удаление | Реализация |
|---|---|---|---|---|---|
| Дискеты 160K…2.88M (FAT12) | да | да, 8 стандартных форматов | да | да | своя |
| FAT12 / FAT16 / FAT32 на HDD | да | да | да | да | своя |
| ISO 9660 + Joliet (CD/DVD) | да, + Rock Ridge | да | да (пересборка) | да (пересборка) | своя |
| NTFS | да | через `mkntfs` | через libntfs-3g | через libntfs-3g | чтение своё |
| Контейнер raw (.img/.ima) | да | да | — | — | своя |
| Контейнер VHD fixed / dynamic | да | да | — | — | своя |
| MBR (с расширенными разделами), GPT | да | MBR | — | — | своя |

Дополнительно: команда `convert` (raw ↔ VHD fixed ↔ VHD dynamic), графическая
оболочка `diskimg-gui`, вывод дерева, `cat` файла в stdout.

## Архитектура

```
 Файл образа
     │
     ▼
 Контейнер (BlockDevice)  ── FileDevice (raw) │ VhdDevice (fixed / dynamic)
     │
     ▼
 Таблица разделов ───────── MBR / EBR / GPT → SliceDevice (окно раздела)
     │
     ▼
 Файловая система ───────── FatFS │ NtfsFS + NtfsWriter │ IsoFS
     │                      общий интерфейс FileSystem (fsbase.py)
     ▼
 CLI (cli.py) / GUI (gui.py)
```

Каждый слой знает только интерфейс нижнего: FAT работает одинаково на дискете,
в разделе raw-диска и в разделе dynamic VHD.

| Модуль | Что внутри |
|---|---|
| `blockdev.py` | интерфейс блочного устройства, сырой файл, окно-раздел, разреженное копирование |
| `vhd.py` | footer/dynamic header/BAT, контрольные суммы, геометрия CHS по спецификации, выделение блоков |
| `partition.py` | разбор MBR, цепочки EBR, GPT; запись MBR с мини-загрузчиком |
| `fat.py` | BPB, таблица FAT (12/16/32 бит), цепочки кластеров, каталоги, LFN, имена 8.3 с `~N`, FSInfo, mkfs |
| `iso9660.py` | PVD/SVD, Joliet, Rock Ridge (SUSP: SP/NM/CE), мультиэкстенты; сборщик образа с таблицами путей L/M |
| `ntfs.py` | загрузочный сектор, MFT, fixups, атрибуты, runlist, `$ATTRIBUTE_LIST`, дерево по `$FILE_NAME` |
| `ntfs3g.py` | запись в NTFS через ctypes-обвязку libntfs-3g, без FUSE и прав root |
| `image.py` | автоопределение формата, открытие, создание, конвертация |

### Ключевые решения

- **FAT.** Таблица FAT держится в памяти как `bytearray`, грязные секторы
  отслеживаются и пишутся во все копии FAT при закрытии. Короткие имена
  генерируются как в Windows (`PROGRA~1`, кириллица в cp866), для имён вида
  `readme.txt` используются NT-флаги регистра без лишних LFN-записей.
  Перед записью проверяется свободное место — образ не остаётся
  полузаписанным.
- **ISO 9660** по природе только для чтения: изменения накапливаются в дереве
  в памяти, при закрытии образ пересобирается во временный файл и атомарно
  заменяет старый (`os.replace`). Данные неизменённых файлов копируются из
  старого образа потоково, без загрузки в память. Пишутся два дерева:
  ISO 9660 level 2 (транслит, `DOKUMENTY`) и Joliet (полные Unicode-имена до 64 символов).
- **VHD dynamic.** Новый блок записывается на место footer'а, footer переносится
  в конец; запись нулей в невыделенный блок пропускается — образ остаётся
  разреженным. Размер диска выравнивается по геометрии CHS, поэтому Windows и
  qemu видят одинаковый размер.
- **NTFS.** Чтение — собственный парсер. Запись в B+-деревья индексов, `$Bitmap`,
  `$LogFile` с нуля — объём полноценного драйвера, поэтому она делегирована
  libntfs-3g (та же библиотека, что у `ntfs-3g`/`ntfscp`). Раздел выгружается
  во временный разреженный файл, после операций обратно пишутся только
  изменившиеся блоки.
- **Безопасность извлечения.** Имена из образа санитизируются
  (`../` и `/` внутри имени не дают выйти за каталог назначения), `..` в путях
  внутри образа запрещён.

## Установка

```bash
# Python ≥ 3.8, без сторонних Python-пакетов
sudo apt install ntfs-3g          # только для NTFS (libntfs-3g + mkntfs)
pip install .                     # или запуск без установки: python3 -m diskimg
```

## Использование

```bash
# создание
diskimg create floppy.img --type floppy --floppy 1.44M --label BOOT
diskimg create cd.iso --label MY_CD --from ./site
diskimg create disk.vhd --size 512M --fs fat32 --label DATA      # dynamic VHD + MBR
diskimg create win.vhd  --size 1G --fs ntfs --vhd-type fixed
diskimg create hdd.img  --size 64M --fs fat16 --no-mbr           # «суперфлоппи»

# просмотр
diskimg info disk.vhd
diskimg ls -l -R cd.iso
diskimg tree win.vhd
diskimg cat floppy.img /readme.txt

# извлечение
diskimg extract disk.vhd -o ./out                    # всё
diskimg extract cd.iso /docs /readme.txt -o ./out    # выборочно

# изменение
diskimg add disk.vhd report.pdf ./photos -d /backup  # добавить/заменить (рекурсивно)
diskimg add disk.vhd new.txt -n "старое имя.txt"     # заменить под другим именем
diskimg mkdir win.vhd --parents /a/b/c
diskimg rm disk.vhd -r /backup/photos

# конвертация контейнера
diskimg convert disk.vhd disk.raw --to raw
diskimg convert disk.raw disk-fixed.vhd --to fixed

# если на диске несколько разделов
diskimg ls multi.img -p 2
```

Графический интерфейс: `diskimg-gui [образ]` (Tkinter) — навигация двойным
щелчком, извлечение, добавление файлов/папок, удаление, создание образа, свойства.

## Тестирование

`tests/test_all.py` — 35 тестов. Принцип: **всё, что создал или изменил
diskimg, проверяется независимыми инструментами, и наоборот**.

| Проверка | Чем |
|---|---|
| Все 8 форматов дискет, FAT12/16/32 с MBR и без | `fsck.fat -n` — 0 ошибок |
| Содержимое FAT побайтно | `mcopy` / `mtype` (mtools) |
| 400 случайных операций записи/удаления против модели | `fsck.fat` + сверка данных |
| Фрагментированный файл (цепочка с разрывами) | `mtype` |
| Чтение FAT, созданной `mkfs.fat` + `mcopy` | своё извлечение = исходник |
| VHD fixed/dynamic: побайтное совпадение диска | `qemu-img convert -f vpc` |
| Запись в VHD, созданные qemu-img | `qemu-img` + `mtype` |
| ISO: корректность, затем изменение | `isoinfo -d`, `xorriso -check_media`, `xorriso -extract` |
| Чтение ISO от xorriso: RR+Joliet, Joliet, RR, чистый ISO 9660 | своё извлечение |
| NTFS в VHD и raw: создание, замена, `rm -r`, mkdir | `ntfsfix -n`, `ntfscat` |
| Чтение NTFS, наполненной `ntfscp` (150 файлов + 6 МБ) | свой парсер |
| Path traversal, ошибки, нехватка места, переполнение корня FAT12 | — |

```bash

```

## Ограничения

- NTFS: сжатые (LZNT1) и зашифрованные (EFS) файлы распознаются, но не
  читаются; запись требует libntfs-3g.
- ISO: при пересборке не сохраняется загрузочная запись El Torito
  (выдаётся предупреждение); файлы ≥ 4 ГиБ читаются (мультиэкстент), но не
  записываются; UDF (часть DVD) не поддерживается — читается ISO-мост.
- VHD differencing (с родительским диском) не поддерживается; VHDX — другой формат.
- GPT только на чтение (создаётся MBR).
- Атрибуты «только чтение/скрытый» и время создания при добавлении не переносятся;
  время изменения сохраняется для FAT и ISO.
